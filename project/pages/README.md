# App page designs (Claude Design export)

The nine business-app screen designs from the **MyGig Design System** Claude Design project
(`mygig-design-system-019e00fe-4068-7058-af69-1d9b37e1468f`), exported 2026-07-27 and committed
here so implementation work isn't blocked on access to the design project.

Pages: Business Signin & Signup · Business Onboarding · Business Dashboard · Post a Shift
(+ Standalone) · Select Workers (+ Manual) · Review & Post · Edit Billing Method.

Asset references are rewritten from the export's `_ds/mygig-design-system-…/` bundle paths to the
sibling `project/` files (`../colors_and_type.css`, `../_ds_bundle.js`, `../assets/…`), so the pages
render from this repo. Worker photos used by the dashboard/select-workers mocks live in
`assets/workers/`.

These files are the design source of truth for the business-app UX refresh — re-export from the
Claude Design project rather than editing them by hand.
